# EXFIL ZONE · 撤离区

> 网页运行版的硬核撤离射击（Extraction Shooter）—— 3D 第一人称 + 像素风体素，局域网 2–8 人 + SCAV AI。
> 浏览器直接玩，服务端是 Node，**无需安装客户端、无需 Unity**。

---

## 这是什么

一个以《逃离塔科夫》为蓝本的玩法学习项目：**带装备进图 → 搜刮 → 打或躲 → 撤离保本 / 阵亡全损**。

已实现的核心循环：

| 系统 | 状态 |
|---|---|
| 撤离循环（进图 → 搜刮 → 撤离/阵亡 → 结算落档） | ✅ |
| 塔科夫式网格仓库（按物品尺寸占格、可旋转、装备槽 7 格） | ✅ |
| 装备容器（胸挂/背包各自独立格子，胸挂内可快捷使用） | ✅ |
| 弹药物理（弹药是实体堆叠条目，可拆包、有口径与**穿深**） | ✅ |
| **护甲 / 穿透 / 命中部位**（头/胸判定、防护等级、耐久损耗） | ✅ |
| SCAV AI（视野+听觉感知、A* 寻路、状态机、尸体可搜刮） | ✅ |
| 局域网联机（房间/大厅、服务器权威、**预测-回滚-重放**同步） | ✅ |
| 商人经济（买卖弹药/药品/**护具**、武器） | ✅ |
| 单机离线（localStorage 档案，零网络） | ✅ |

尚未实现：任务系统、藏身处、保险、多地图、BOSS、断线重连、新手引导。

## 快速开始

### 方式一：便携包（推荐给玩家）

1. 下载 `exfil-zone-demo-v0.15.1.zip`（内置 Node，31.9 MB）
2. 解压到任意目录
3. 双击 **`启动游戏.bat`** → 浏览器自动打开 `http://localhost:9090`

### 方式二：从源码跑（推荐给开发者）

```bash
npm install          # 只依赖 three 与 ws
npm start            # = node server/server.js
# 浏览器打开 http://localhost:9090
```

端口默认 **9090**（`PORT` 环境变量可覆盖）。

### 局域网联机

1. 每台机器各自跑一份服务
2. 都打开 `http://localhost:9090` → 点「局域网联机」
3. 房主点「创建房间 · 成为房主」，其他人从**自动发现**的房间列表点进去（UDP 9099 广播，无需手输 IP）
4. 想以 SCAV 身份出战：房间页点「以 SCAV 身份出战」

> 首次运行若弹 Windows 防火墙提示，请选「允许访问」，否则局域网内其他设备连不上。

### 操作

| 按键 | 功能 |
|---|---|
| `W A S D` | 移动 |
| 鼠标 | 视角（点击锁定指针） |
| 左键 | 射击 |
| `R` | 换弹（**不是**重生） |
| `F` | 打开容器（塔科夫式逐件拿取） |
| `Tab` | 局内背包 |
| 空格 | 跳跃 |
| `Enter` | 单机阵亡后重生 |

## 项目结构

```
server/            多人模式薄壳：HTTP + WebSocket 传输 + GameSim 调度
  server.js        ├ 服务器权威主循环（60Hz tick + 30Hz 快照）
  data.js          └ 存档层（JSON 档案）
shared/            双兼容模块（Node CJS + 浏览器 script，IIFE 包裹）
  sim.js           GameSim 模拟层（单机/联机共用，含战斗与护甲结算）
  core.js          物理 / 碰撞 / 射线 / A* 寻路
  grid.js          网格仓库与装备槽纯函数
  containers.js    装备容器（胸挂/背包）纯函数
  loadout.js       档案契约层（stash ↔ grid/equipment 双向同步）
  items.js         物品 / 武器实例 / 交易 / 结算
  predict.js       客户端预测-和解步进
  config.js        三层默认配置（JSON 权威 → DEFAULTS 兜底 → 代码兜底）
  map.js           地图数据（单一数据源）
public/            客户端：渲染 / 输入 / 音频 / UI
  game.js          ├ 渲染循环、输入、整备界面、局内 HUD
  index.html       └ 页面结构
config/            tuning.json（平衡数值）+ content.json（内容表）
maps/              factory.json（体素地图源）
test/              单元测试（570 条）
verify.js          端到端验收（25 项，数据流未实测即 FAIL）
```

**架构要点**：服务器权威；客户端预测-回滚-重放（**不用 EMA 平滑掩盖**）；数值与逻辑分离（改 JSON 即生效）；物理参数单一数据源。
